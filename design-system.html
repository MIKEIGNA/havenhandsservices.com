Typography

Two font families: Outfit (headings) and Inter (body). Loaded from Google Fonts.

Outfit (Headings)

Heading 1

Heading 2

Heading 3

Heading 4

font-family: 'Outfit', sans-serif;
font-weight: 300, 400, 500, 600, 700, 800

Inter (Body)

Body text — this is how regular paragraph text looks. The line height is 1.65 for comfortable reading. Color uses --text.

Small / muted text using --text-muted.

font-family: 'Inter', sans-serif;
line-height: 1.65;
color: var(--text) or var(--text-muted)

Headings CSS

h1, h2, h3, h4, h5, h6 {
font-family: 'Outfit', sans-serif;
line-height: 1.2;
color: var(--dark);
}
